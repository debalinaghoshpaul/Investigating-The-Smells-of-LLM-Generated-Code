**Java Program:**

```java
import java.util.Scanner;

public class StringStartsWith {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Read input strings
        System.out.println("Enter the main string: ");
        String mainString = scanner.nextLine();

        System.out.println("Enter the starting string: ");
        String startingString = scanner.nextLine();

        // Check if the main string starts with the starting string
        boolean startsWith = mainString.startsWith(startingString);

        // Print the result
        if (startsWith) {
            System.out.println("The main string starts with the starting string.");
        } else {
            System.out.println("The main string does not start with the starting string.");
        }
    }
}
```

**Test Cases:**

**Positive Test Cases:**

* **Input 1:**
    * mainString: "Hello World"
    * startingString: "Hello"
    * **Output:** "The main string starts with the starting string."
* **Input 2:**
    * mainString: "Programming is fun!"
    * startingString: "Programming"
    * **Output:** "The main string starts with the starting string."

**Negative Test Cases:**

* **Input 1:**
    * mainString: "Java is awesome"
    * startingString: "Python"
    * **Output:** "The main string does not start with the starting string."
* **Input 2:**
    * mainString: "" (empty string)
    * startingString: "Hello"
