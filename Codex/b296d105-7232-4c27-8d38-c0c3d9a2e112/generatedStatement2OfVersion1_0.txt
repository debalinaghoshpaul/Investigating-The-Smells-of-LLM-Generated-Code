**Corner cases:**

* **Input:** `[9, 9, 9, 9]`
* **Output:** `[1, 0, 0, 0, 0]`
* **Explanation:** This is the case where all digits are 9. Adding 1 to the least significant digit results in a carry-over to all the other digits, producing the result `[1, 0, 0, 0, 0]`.

* **Input:** `[0]`
* **Output:** `[1]`
* **Explanation:** This is the case where the number represented by the array is 0. Adding 1 to 0 results in the result `[1]`.

* **Input:** `[9]`
* **Output:** `[1, 0]`
* **Explanation:** This is the case where the number represented by the array is 9. Adding 1 to 9 results in a carry-over to the most significant digit, producing the result `[1, 0]`.

**Normal cases:**

* **Input:** `[9, 8, 7, 6]`
* **Output:** `[9, 8, 7, 7]`
* **Explanation:** This is a normal case where there is a carry-over from the least significant digit to the next digit. The result is `[9, 8, 7, 7]`.
