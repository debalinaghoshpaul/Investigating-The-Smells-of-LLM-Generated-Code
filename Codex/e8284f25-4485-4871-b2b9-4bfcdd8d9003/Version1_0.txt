```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class AverageStringLength {

    public static void main(String[] args) {
        // Create a list of strings
        List<String> strings = Arrays.asList("This", "is", "a", "list", "of", "strings");

        // Find the average length of the strings in the list using a lambda expression
        double averageLength = strings.stream()
                .mapToInt(String::length)
                .average()
                .getAsDouble();

        // Print the average length
        System.out.println("The average length of the strings in the list is: " + averageLength);
    }
}
```

**Test cases:**

* **Empty list:**
```
Input: []
Expected output: 0.0
```

* **List with one string:**
```
Input: ["Hello"]
Expected output: 5.0
```

* **List with multiple strings of different lengths:**
```
Input: ["This", "is", "a", "list", "of", "strings"]
Expected output: 4.0
```

* **List with strings containing spaces:**
```
Input: ["This", "is", "a", "list", "of", "strings with spaces"]
Expected output: 5.2
```

* **List with strings containing special characters:**
```
Input: ["This", "is", "a", "list", "of", "strings with special characters!"]
Expected output: 5.6
```
