```java
import java.util.Scanner;

public class IntegerToString {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Input an integer: ");
        int number = scanner.nextInt();

        // Convert the integer to a string using the String.valueOf() method
        String stringNumber = String.valueOf(number);

        // Print the string format of the integer
        System.out.println("String format of the said integer: " + stringNumber);
    }
}
```

**Test Cases:**

* **Normal case:**
    * Input: 123
    * Expected output: 123
* **Negative case:**
    * Input: -456
    * Expected output: -456
* **Zero case:**
    * Input: 0
    * Expected output: 0
* **Corner case (very large integer):**
    * Input: 9223372036854775807
    * Expected output: 9223372036854775807
* **Corner case (very small integer):**
    * Input: -9223372036854775808
    * Expected output: -9223372036854775808
