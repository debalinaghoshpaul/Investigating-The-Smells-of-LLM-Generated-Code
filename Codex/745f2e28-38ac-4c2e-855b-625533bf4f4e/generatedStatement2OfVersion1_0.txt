

**Test Cases:**

**Corner Cases:**

* **Empty array:** `arr = []`
* **Array length less than k:** `arr = [1, 2], k = 3`
* **Negative values in array:** `arr = [-1, -2, -3], k = 2`
* **k greater than array length:** `arr = [1, 2, 3], k = 4`

**Regular Cases:**

* **Array with positive and negative values:** `arr = [1, 12, -5, -6, 50, 3], k = 4`
* **Array with no negative values:** `arr = [10, 20, 30, 40], k = 2`
* **Array with all negative values:** `arr = [-1, -2, -3, -4], k = 2`
* **Array with all equal values:** `arr = [1, 1, 1, 1, 1], k = 5`
