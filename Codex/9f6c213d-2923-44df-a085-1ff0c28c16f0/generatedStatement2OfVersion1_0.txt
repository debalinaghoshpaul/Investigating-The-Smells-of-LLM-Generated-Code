
In this Java program, we have created an interface `Searchable` with a method `search(String keyword)` that searches for a given keyword. We have implemented this interface in two classes `Document` and `WebPage` with their own implementations of the `search()` method.

The `Document` class represents a document with some content, and the `search()` method searches for the keyword in the document's content. The `WebPage` class represents a webpage with a URL, and the `search()` method will perform the search on the webpage's content from the given URL.

In the `main` method, we have created instances of `Document` and `WebPage` classes and tested the `search()` method by searching for different keywords on them.
