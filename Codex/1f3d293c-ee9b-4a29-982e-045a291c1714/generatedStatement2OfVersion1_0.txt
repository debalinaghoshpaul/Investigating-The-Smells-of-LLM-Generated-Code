

**Test Cases:**

* **Valid Cases:**
    * "abcd1234"
    * "AbCd1234"
    * "ABCDefg1234"
    * "1234567890"

* **Invalid Cases:**
    * "abc def" (Contains spaces)
    * "123 456" (Contains spaces)

**Corner Cases:**

* **Empty string:** "" (Should return true)
* **String containing only numbers:** "1234567890" (Should return true)
* **String containing only letters:** "abcdefghijklmnopqrstuvwxyz" (Should return true)
* **String containing only uppercase letters:** "ABCDEFGHIJKLMNOPQRSTUVWXYZ" (Should return true)
* **String containing a mix of letters and numbers:** "abc123def456" (Should return true)
