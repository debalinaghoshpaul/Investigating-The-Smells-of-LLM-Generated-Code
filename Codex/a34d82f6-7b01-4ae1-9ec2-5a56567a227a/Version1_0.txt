```java
import java.util.TimeZone;

public class TimeZones {

    public static void main(String[] args) {
        // Get all available time zones in UTC
        String[] utcTimeZones = TimeZone.getAvailableIDs("UTC");
        System.out.println("UTC Time Zones:");
        for (String timeZone : utcTimeZones) {
            System.out.println(timeZone);
        }

        // Get all available time zones in GMT
        String[] gmtTimeZones = TimeZone.getAvailableIDs("GMT");
        System.out.println("\nGMT Time Zones:");
        for (String timeZone : gmtTimeZones) {
            System.out.println(timeZone);
        }
    }
}
```

**Test Cases:**

**Normal Cases:**

* Input: None
* Expected Output: A list of all available time zones in UTC and GMT.

**Corner Cases:**

* Input: An invalid time zone ID
* Expected Output: An error message indicating that the time zone ID is invalid.
* Input: A null time zone ID
* Expected Output: An error message indicating that the time zone ID is null.
* Input: A time zone ID that is not supported by the Java Virtual Machine
* Expected Output: An error message indicating that the time zone ID is not supported.
