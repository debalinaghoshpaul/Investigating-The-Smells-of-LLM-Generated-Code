

**Test cases:**

* **Normal case:** Find the 3 smallest elements in the array [1, 4, 17, 7, 25, 3, 100]. Expected output: 1, 3, 4.
* **Corner case 1:** Find the k smallest elements in an empty array. Expected output: An empty array.
* **Corner case 2:** Find the k smallest elements in an array with k being greater than the size of the array. Expected output: An array of all the elements in the original array, sorted in ascending order.
* **Corner case 3:** Find the k smallest elements in an array with all the elements being the same. Expected output: An array of the k smallest elements, which are all the same.
