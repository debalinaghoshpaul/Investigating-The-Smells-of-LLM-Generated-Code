**Java Program:**

```java
import java.util.Scanner;

public class ToastSubstring {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a string: ");
        String str = sc.nextLine();

        int firstIndex = str.indexOf("toast");
        int lastIndex = str.lastIndexOf("toast");

        if (firstIndex == -1 || lastIndex == -1) {
            System.out.println("Substring 'toast' not found.");
        } else {
            String substring = str.substring(firstIndex + 5, lastIndex);
            System.out.println("Substring between 'toast': " + substring);
        }
    }
}
```
