**Java program:**

```java
import java.util.HashMap;
import java.util.Map;

public class CountCharsOverTwice {

    public static void main(String[] args) {
        String input = "Hello123World";

        // Create a map to store the character counts
        Map<Character, Integer> charCounts = new HashMap<>();

        // Iterate over the input string and update the character counts
        for (char c : input.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                int count = charCounts.getOrDefault(c, 0);
                charCounts.put(c, count + 1);
            }
        }

        // Count the number of characters that occur more than twice
        int count = 0;
        for (Map.Entry<Character, Integer> entry : charCounts.entrySet()) {
            if (entry.getValue() > 2) {
                count++;
            }
        }

        // Print the count
        System.out.println("Number of characters that occur more than twice: " + count);
    }
}
```

**Test case 5:**

Expected output: 0 (no characters occur)
