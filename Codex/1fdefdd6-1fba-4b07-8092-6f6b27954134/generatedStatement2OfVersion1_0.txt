

This Java program demonstrates how to use the `ScheduledExecutorService` interface to schedule tasks for execution at a specified time or with a fixed delay. The program creates a single-threaded executor, defines a task to be executed, schedules the task to run after a delay of 3 seconds, schedules the task to run periodically with an initial delay of 2 seconds and a fixed rate of 5 seconds, and finally shuts down the executor after 20 seconds.
