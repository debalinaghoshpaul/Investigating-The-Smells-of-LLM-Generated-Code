**Java program:**

```java
import java.util.Scanner;

public class FirstAndLastCharacters {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Get the input string from the user
        System.out.println("Enter a string: ");
        String str = scanner.nextLine();

        // Get the number of characters to take from the first and last positions
        System.out.println("Enter the number of characters to take from the first and last positions: ");
        int numChars = scanner.nextInt();

        // Create a new string by taking the specified number of characters from the first and last positions
        String newStr = str.substring(0, numChars) + str.substring(str.length() - numChars);

        // Print the new string
        System.out.println("The new string is: " + newStr);
    }
}
```
