```java
import java.time.LocalDate;
import java.time.LocalTime;

public class DisplayDateAndTime {

    public static void main(String[] args) {
        // Get the current date without time
        LocalDate date = LocalDate.now();
        System.out.println("Current date without time: " + date);

        // Get the current time without date
        LocalTime time = LocalTime.now();
        System.out.println("Current time without date: " + time);
    }
}
```

**Test Cases:**

**Normal Case:**

* Input: None
* Expected Output:
```
Current date without time: 2023-03-08
Current time without date: 10:15:30.456
```

**Corner Cases:**

* **Invalid date:**
    * Input: A date that does not exist, e.g. 2023-02-31
    * Expected Output: An exception should be thrown
* **Invalid time:**
    * Input: A time that does not exist, e.g. 24:00:00
    * Expected Output: An exception should be thrown
* **Empty input:**
    * Input: None
    * Expected Output: The program should still display the current date and time without errors
