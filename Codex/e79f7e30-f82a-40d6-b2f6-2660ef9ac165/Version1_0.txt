```java
import java.nio.charset.Charset;
import java.util.SortedMap;

public class ListCharSets {

    public static void main(String[] args) {
        SortedMap<String, Charset> charsets = Charset.availableCharsets();
        for (String csName : charsets.keySet()) {
            System.out.println(csName);
        }
    }
}
```

**Test cases:**

* **Normal case:** The program should list all available character sets.
* **Empty case:** The program should not list any character sets if none are available.
* **Special character case:** The program should list character sets with special characters in their names, such as "Big5-HKSCS".
