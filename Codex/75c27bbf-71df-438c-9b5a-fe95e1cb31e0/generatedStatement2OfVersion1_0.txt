

**Test cases:**

* **Normal case:** A file with valid contents is provided to the program.
* **Empty file:** An empty file is provided to the program.
* **Non-existent file:** A file that does not exist is provided to the program.
* **Invalid file:** A file that cannot be read is provided to the program.
* **Large file:** A file with a large number of bytes is provided to the program.
* **Special characters:** A file with special characters is provided to the program.
