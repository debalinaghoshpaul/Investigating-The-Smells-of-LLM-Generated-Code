```java
import java.util.*;

public class MovePositiveAndNegativeNumbers {

    public static void main(String[] args) {
        int[] arr = {-2, 3, 4, -1, -3, 1, 2, -4, 0};
        movePositiveAndNegativeNumbers(arr);
        System.out.println("Result: " + Arrays.toString(arr));
    }

    public static void movePositiveAndNegativeNumbers(int[] arr) {
        int i = 0;
        int j = arr.length - 1;
        while (i < j) {
            if (arr[i] < 0) {
                if (arr[j] > 0) {
                    int temp = arr[i];
                    arr[i] = arr[j];
                    arr[j] = temp;
                    i++;
                    j--;
                } else {
                    j--;
                }
            } else {
                i++;
            }
        }
    }
}
```

Test cases:

* **Corner cases:**
    * An array with all positive numbers: `[1, 2, 3, 4, 5]`
    * An array with all negative numbers: `[-1, -2, -3, -4, -5]`
    * An array with only one element: `[0]`
* **Normal cases:**
    * An array with both positive and negative numbers: `[-2, 3, 4, -1, -3, 1, 2, -4, 0]`
    * An array with positive and negative numbers in alternating order: `[-1, 1, -2, 2, -3, 3, -4, 4]`
    * An array with positive and negative numbers in random order: `[-4, -3, -2, -1, 0, 1, 2, 3, 4]`
