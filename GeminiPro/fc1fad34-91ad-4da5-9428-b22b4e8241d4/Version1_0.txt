```java
import java.util.*;
class AngleBetweenHands {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int h = sc.nextInt();
        int m = sc.nextInt();
        double angle = Math.abs(((h % 12) * 60 + m) - 60 * m) / 2;
        System.out.println(angle + " degrees");
    }
}
```

**Test Cases:**

**Normal Case:**

* Input: h = 12, m = 30
* Expected Output: 165 degrees

**Corner Cases:**

* **h = 0, m = 0:**
    * Expected Output: 0 degrees
* **h = 12, m = 0:**
    * Expected Output: 0 degrees
* **h = 3, m = 30:**
    * Expected Output: 7.5 degrees
* **h = 9, m = 0:**
    * Expected Output: 90 degrees
* **h = 6, m = 30:**
    * Expected Output: 165 degrees
* **h = 12, m = 59:**
    * Expected Output: 359.5 degrees
