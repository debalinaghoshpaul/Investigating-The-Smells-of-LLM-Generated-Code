```java
import java.util.Calendar;
import java.util.Date;

public class CreateDateUsingCalendar {

    public static void main(String[] args) {
        // Create a Calendar object
        Calendar calendar = Calendar.getInstance();

        // Set the year, month, day, hour, minute, and second
        calendar.set(Calendar.YEAR, 2023);
        calendar.set(Calendar.MONTH, Calendar.MARCH);
        calendar.set(Calendar.DAY_OF_MONTH, 8);
        calendar.set(Calendar.HOUR_OF_DAY, 12);
        calendar.set(Calendar.MINUTE, 30);
        calendar.set(Calendar.SECOND, 0);

        // Create a Date object using the Calendar object
        Date date = calendar.getTime();

        // Print the Date object
        System.out.println(date);
    }
}
```

**Test Cases:**

**Valid Test Cases:**

1. Create a date object for March 8, 2023, at 12:30 PM.
2. Create a date object for January 1, 2020, at 00:00 AM.
3. Create a date object for December 31, 2024, at 11:59 PM.

**Corner Cases:**

1. Create a date object for an invalid year (e.g., -1000).
2. Create a date object for an invalid month (e.g., 13).
3. Create a date object for an invalid day (e.g., 31 for February in a non-leap year).
4. Create a date object for an invalid hour (e.g., 25).
5. Create a date object for an invalid minute (e.g., 61).
6. Create a date object for an invalid second (e.g., 62).
