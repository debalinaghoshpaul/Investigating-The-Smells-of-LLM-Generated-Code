

**Test Cases**

**Normal Case**

* Start URL: https://www.google.com/
* Max URLs to crawl: 10

**Edge Case: Empty Start URL**

* Start URL: null
* Max URLs to crawl: 10

**Edge Case: Empty List of Pending URLs**

* Start URL: https://www.google.com/
* Max URLs to crawl: 0

**Edge Case: Invalid Start URL (404 Error)**

* Start URL: https://www.example.com/non-existent-page
* Max URLs to crawl: 10

**Edge Case: Cyclic URL Structure**

* Start URL: https://www.example.com/page1
* Max URLs to crawl: 10
* page1 contains a link to itself

**Edge Case: Large Number of URLs**

* Start URL: https://www.wikipedia.org/
* Max URLs to crawl: 10000
