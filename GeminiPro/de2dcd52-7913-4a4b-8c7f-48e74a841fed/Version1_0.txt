```java
import java.util.Scanner;

public class FahrenheitToCelsius {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // Read the temperature in Fahrenheit
        System.out.print("Input a degree in Fahrenheit: ");
        double fahrenheit = input.nextDouble();

        // Convert the temperature to Celsius
        double celsius = (fahrenheit - 32) * 5 / 9;

        // Print the result
        System.out.println(fahrenheit + " degree Fahrenheit is equal to " + celsius + " in Celsius");
    }
}
```

**Test Cases:**

* **Normal case:** Input a degree in Fahrenheit: 212
* **Corner case:** Input a degree in Fahrenheit: -40
* **Corner case:** Input a degree in Fahrenheit: 0
* **Corner case:** Input a degree in Fahrenheit: 100
* **Invalid input:** Input a degree in Fahrenheit: "abc"
