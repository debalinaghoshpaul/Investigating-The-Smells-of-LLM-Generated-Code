**Merge Two Sorted Arrays**

```java
import java.util.Arrays;

public class MergeSortedArrays {

    public static void main(String[] args) {
        int[] array1 = {1, 2, 3, 4};
        int[] array2 = {2, 5, 7, 8};

        int[] result = mergeSortedArrays(array1, array2);

        System.out.println(Arrays.toString(result)); // [1,2,2,3,4,5,7,8]
    }

    public static int[] mergeSortedArrays(int[] array1, int[] array2) {
        int[] mergedArray = new int[array1.length + array2.length];
        int i = 0;
        int j = 0;
        int k = 0;

        while (i < array1.length && j < array2.length) {
            if (array1[i] <= array2[j]) {
                mergedArray[k] = array1[i];
                i++;
            } else {
                mergedArray[k] = array2[j];
                j++;
            }
            k++;
        }

        while (i < array1.length) {
            mergedArray[k] = array1[i];
            i++;
            k++;
        }

        while (j < array2.length) {
            mergedArray[k] = array2[j];
            j++;
            k++;
        }

        return mergedArray;
    }
}
```

**Test Cases for Merge Two Sorted Arrays**

* **Corner cases:**
    * Empty arrays: `array1 = [], array2 = []`
    * Single-element arrays: `array1 = [1], array2 = [2]`
    * Arrays with duplicate elements: `array1 = [1, 2, 3], array2 = [2, 4, 5]`
    * Arrays with negative elements: `array1 = [-1, 0, 1], array2 = [-2, -1, 0]`

* **Normal cases:**
    * Arrays of equal length: `array1 = [1, 3, 5], array2 = [2, 4, 6]`
    * Arrays of different length: `array1 = [1, 2, 3, 4], array2 = [5, 6, 7]`

**Rotate a String**

```java
public class RotateString {

    public static void main(String[] args) {
        String str = "abcde";
        int offset = 2;

        String rotatedString = rotateString(str, offset);

        System.out.println(rotatedString); // "cdeab"
    }

    public static String rotateString(String str, int offset) {
        StringBuilder sb = new StringBuilder();

        offset = offset % str.length();

        for (int i = offset; i < str.length(); i++) {
            sb.append(str.charAt(i));
        }

        for (int i = 0; i < offset; i++) {
            sb.append(str.charAt(i));
        }

        return sb.toString();
    }
}
```

**Test Cases for Rotate a String**

* **Corner cases:**
    * Empty string: `str = ""`
    * Offset greater than string length: `str = "abc", offset = 5`
    * Negative offset: `str = "abc", offset = -2`

* **Normal cases:**
    * Offset within string length: `str = "abcde", offset = 2`
    * Offset equal to string length: `str = "abcde", offset = 5`
