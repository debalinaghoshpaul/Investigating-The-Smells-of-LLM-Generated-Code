```java
import java.util.Scanner;

public class MultiplyArrays {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // Get the size of the arrays
        System.out.print("Enter the size of the first array: ");
        int size1 = input.nextInt();
        System.out.print("Enter the size of the second array: ");
        int size2 = input.nextInt();

        // Create the arrays
        int[] array1 = new int[size1];
        int[] array2 = new int[size2];

        // Get the elements of the arrays
        System.out.println("Enter the elements of the first array: ");
        for (int i = 0; i < size1; i++) {
            array1[i] = input.nextInt();
        }
        System.out.println("Enter the elements of the second array: ");
        for (int i = 0; i < size2; i++) {
            array2[i] = input.nextInt();
        }

        // Multiply the corresponding elements of the arrays
        int[] result = new int[size1];
        for (int i = 0; i < size1; i++) {
            result[i] = array1[i] * array2[i];
        }

        // Print the result
        System.out.println("Result: ");
        for (int i = 0; i < size1; i++) {
            System.out.print(result[i] + " ");
        }
        System.out.println();
    }
}
```

**Test Cases:**

**Positive Test Cases:**

* **Input:**
    * Array1: [1, 3, -5, 4]
    * Array2: [1, 4, -5, -2]
* **Expected Output:**
    * Result: 1 12 25 -8

* **Input:**
    * Array1: [2, 4, 6, 8]
    * Array2: [1, 3, 5, 7]
* **Expected Output:**
    * Result: 2 12 30 56

* **Input:**
    * Array1: [0, 0, 0]
    * Array2: [1, 2, 3]
* **Expected Output:**
    * Result: 0 0 0

**Negative Test Cases:**

* **Input:**
    * Array1: []
    * Array2: [1, 2, 3]
* **Expected Output:**
    * Error: Array1 is empty

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: []
* **Expected Output:**
    * Error: Array2 is empty

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: [1, 2]
* **Expected Output:**
    * Error: Arrays are not of equal size

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: [1, null, 3]
* **Expected Output:**
    * Error: Array2 contains null value

**Corner Cases:**

* **Input:**
    * Array1: [Integer.MAX_VALUE, Integer.MAX_VALUE]

* **Expected Output:**
    * Result: Overflow error

* **Input:**
    * Array1: [Integer.MIN_VALUE, Integer.MIN_VALUE]
    * Array2: [Integer.MIN_VALUE, Integer.MIN_VALUE]
* **Expected Output:**
