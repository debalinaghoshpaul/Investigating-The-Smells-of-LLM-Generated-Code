**Java Program:**

```java
import java.util.Scanner;

public class RemoveCharacterFromString {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Get the input string from the user
        System.out.print("Enter the input string: ");
        String inputString = scanner.nextLine();

        // Get the character to be removed from the user
        System.out.print("Enter the character to be removed: ");
        char characterToRemove = scanner.next().charAt(0);

        // Create a new string after removing the specified character
        String newString = inputString.substring(0, 1) + inputString.substring(1, inputString.length() - 1).replaceAll(String.valueOf(characterToRemove), "") + inputString.substring(inputString.length() - 1);

        // Print the new string
        System.out.println("New string: " + newString);
    }
}
```
