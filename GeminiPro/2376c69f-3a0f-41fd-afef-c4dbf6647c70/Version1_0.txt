```java
import java.util.Arrays;

public class CatalanNumbers {

  public static void main(String[] args) {
    // Print the first 10 Catalan numbers
    int[] catalanNumbers = catalanNumbers(10);
    System.out.println(Arrays.toString(catalanNumbers));
  }

  public static int[] catalanNumbers(int n) {
    int[] catalan = new int[n + 1];

    catalan[0] = 1;
    catalan[1] = 1;

    for (int i = 2; i <= n; i++) {
      catalan[i] = 0;
      for (int j = 0; j < i; j++) {
        catalan[i] += catalan[j] * catalan[i - j - 1];
      }
    }

    return catalan;
  }
}
```

**Test cases:**

**Normal cases:**

* n = 0 => [1]
* n = 1 => [1, 1]
* n = 2 => [1, 1, 2]
* n = 3 => [1, 1, 2, 5]
* n = 4 => [1, 1, 2, 5, 14]

**Corner cases:**

* n = -1 => [0]  // Invalid input, return an empty array
* n = Integer.MAX_VALUE => [1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, ...]  // The array will be too large to store, so it will throw an OutOfMemoryError.
