

**Test cases:**

* **Corner cases:**
    * **Empty array:** `[]`
    * **Array with all 0s:** `[0, 0, 0, 0]`
    * **Array with all 1s:** `[1, 1, 1, 1]`
* **General cases:**
    * **Array with mixed 0s and 1s:** `[0, 1, 0, 1, 0, 1, 0, 1]`
    * **Array with more 0s than 1s:** `[0, 0, 0, 1, 0, 1, 0]`
    * **Array with more 1s than 0s:** `[1, 1, 1, 0, 1, 0, 1]`
