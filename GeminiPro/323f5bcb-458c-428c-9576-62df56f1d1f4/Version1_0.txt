```java
// Instrument.java
abstract class Instrument {
    public abstract void play();
    public abstract void tune();
}

// Glockenspiel.java
class Glockenspiel extends Instrument {
    @Override
    public void play() {
        System.out.println("Plink, plink, plink...");
    }

    @Override
    public void tune() {
        System.out.println("Tuning the glockenspiel...");
    }
}

// Violin.java
class Violin extends Instrument {
    @Override
    public void play() {
        System.out.println("Screech, screech, screech...");
    }

    @Override
    public void tune() {
        System.out.println("Tuning the violin...");
    }
}

// Main.java
public class Main {
    public static void main(String[] args) {
        Glockenspiel glockenspiel = new Glockenspiel();
        Violin violin = new Violin();

        glockenspiel.play();
        glockenspiel.tune();

        violin.play();
        violin.tune();
    }
}
```

**Test Cases:**

* **Normal case:** Create instances of `Glockenspiel` and `Violin` and call the `play()` and `tune()` methods on each instance.
* **Corner cases:**
    * Create an instance of `Instrument` without specifying a subclass.
    * Call the `play()` or `tune()` method on an `Instrument` instance without first creating a subclass instance.

**Expected Output:**

* **Normal case:**
```
Plink, plink, plink...
Tuning the glockenspiel...
Screech, screech, screech...
Tuning the violin...
```

* **Corner cases:**
```
java.lang.AbstractMethodError: Cannot invoke abstract method "void play()" on instance of "java.base/java.lang.Object"
java.lang.AbstractMethodError: Cannot invoke abstract method "void tune()" on instance of "java.base/java.lang.Object"
```
