```java
import java.util.Scanner;

public class CountDigits {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Input an integer number less than ten billion: ");
        int number = scanner.nextInt();
        int count = 0;

        // Handle corner cases
        if (number == 0) {
            count = 1;
        } else if (number < 0 || number >= 10000000000L) {
            System.out.println("Invalid input. Please enter a positive integer less than ten billion.");
            return;
        }

        // Count the number of digits
        while (number > 0) {
            number /= 10;
            count++;
        }

        System.out.println("Number of digits in the number: " + count);
    }
}
```

**Test cases:**

**Normal cases:**

* 125463
* 987654321
* 1

**Corner cases:**

* **0:** This is a corner case because the number of digits in 0 is 1.
* **-1:** This is an invalid input because the number is negative.
* **10000000000:** This is an invalid input because the number is greater than or equal to ten billion.

**Expected outputs:**

* **For 125463:** Number of digits in the number: 6
* **For 987654321:** Number of digits in the number: 9
* **For 1:** Number of digits in the number: 1
* **For 0:** Number of digits in the number: 1
* **For -1:** Invalid input. Please enter a positive integer less than ten billion.
* **For 10000000000:** Invalid input. Please enter a positive integer less than ten billion.
