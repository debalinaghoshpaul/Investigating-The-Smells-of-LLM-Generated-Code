```java
import java.util.Arrays;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class ReverseWords {

  public static void main(String[] args) {
    String str = "Hello World";
    System.out.println(reverseWords(str));  // Output: "dlroW olleH"
  }

  public static String reverseWords(String str) {
    // Check for null or empty string
    if (str == null || str.isEmpty()) {
      return str;
    }

    // Split the string into words
    String[] words = str.split(" ");

    // Reverse each word in the array
    for (int i = 0; i < words.length; i++) {
      words[i] = new StringBuilder(words[i]).reverse().toString();
    }

    // Join the reversed words back into a string
    return Stream.of(words).collect(Collectors.joining(" "));
  }
}
```

**Corner Cases:**

* **Expected Output:** " "
* **Test Case 5:** Input: "" (Empty string)
* **Expected Output:** ""
* **Test Case 6:** Input: null
* **Expected Output:** null

**Additional Considerations:**

* **Punctuation:** The program should preserve any punctuation marks within the words.
