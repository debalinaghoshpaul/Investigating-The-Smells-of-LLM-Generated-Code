```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class ReadFile {

    public static void main(String[] args) {
        try {
            Scanner scanner = new Scanner(new File("input.txt"));
            // Read the file line by line
            while (scanner.hasNextLine()) {
                String line = scanner.nextLine();
                System.out.println(line);
            }
            scanner.close();
        } catch (FileNotFoundException e) {
            // Handle the exception if the file is not found
            System.out.println("File not found.");
        }
    }
}
```

**Test cases:**

* **Empty file:** The file is empty, so the program should throw an exception.
* **Non-empty file:** The file contains some text, so the program should read the file and print the text.
* **File with spaces:** The file contains some text with spaces, so the program should read the file and print the text with spaces.
* **File with newlines:** The file contains some text with newlines, so the program should read the file and print the text with newlines.
* **File with special characters:** The file contains some text with special characters, so the program should read the file and print the text with special characters.
