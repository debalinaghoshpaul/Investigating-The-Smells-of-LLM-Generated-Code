```java
import java.util.*;

public class RearrangeArrayWithSecondElementGreater {

    public static void main(String[] args) {
        int[] nums = {1, 2, 4, 9, 5, 3, 8, 7, 10, 12, 14};
        rearrangeArray(nums);
        System.out.println(Arrays.toString(nums));
    }

    public static void rearrangeArray(int[] nums) {
        int n = nums.length;
        int[] temp = new int[n];
        int i = 0, j = n-1, k = 0;

        while (i <= j) {
            if (i != j) {
                temp[k++] = nums[j--];
            }
            temp[k++] = nums[i++];
        }

        for (i = 0; i < n; i++) {
            nums[i] = temp[i];
        }
    }
}
```

**Test cases:**

**Normal case:**
```
Input: nums = [1, 2, 4, 9, 5, 3, 8, 7, 10, 12, 14]
Output: [1, 4, 2, 9, 3, 8, 5, 10, 7, 14, 12]
```

**Odd-length array:**
```
Input: nums = [1, 2, 4, 9, 5, 3]
Output: [1, 4, 2, 5, 3, 9]
```

**Even-length array with all elements equal:**
```
Input: nums = [1, 1, 1, 1, 1, 1]
Output: [1, 1, 1, 1, 1, 1]
(Note that in this case, the condition is not satisfied, but the program still works)
```

**Corner case:**
```
Input: nums = []
Output: []
(Note that the function should handle empty arrays gracefully)
```
