

**Test Cases:**

**Normal Case:**

* Input: "test.txt"
* Expected Output: "Hello, world!"

**Corner Cases:**

* **Empty File:**
    * Input: "empty.txt" (empty file)
    * Expected Output: ""
* **Non-existent File:**
    * Input: "non-existent.txt" (non-existent file)
    * Expected Output: "Exception: File not found"
* **Read-Only File:**
    * Input: "read-only.txt" (read-only file)
    * Expected Output: "Exception: Permission denied"
* **Write-Only File:**
    * Input: "write-only.txt" (write-only file)
    * Expected Output: "Exception: Permission denied"
