

**Test Cases:**

**1. Positive integers only:**
- Input: nums = {2, 3, 5, 7, 8, 10}
- Output: Pair is (8, 10), Maximum Product: 80

**2. Negative integers only:**
- Input: nums = {-2, -3, -5, -7, -8, -10}
- Output: Pair is (-2, -10), Maximum Product: 20

**3. Mix of positive and negative integers:**
- Input: nums = {2, 3, 5, 7, -7, 5, 8, -5}
- Output: Pair is (7, 8), Maximum Product: 56

**4. Array with duplicate elements:**
- Input: nums = {2, 3, 3, 5, 5, 8, 8}
- Output: Pair is (8, 8), Maximum Product: 64

**5. Array with only one element:**
- Input: nums = {2}
- Output: Error: The array must contain at least two elements.

**6. Array with only zero elements:**
- Input: nums = {0, 0, 0}
- Output: Pair is (0, 0), Maximum Product: 0
