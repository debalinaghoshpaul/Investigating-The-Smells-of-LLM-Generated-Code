```java
import java.util.Scanner;

public class TestIf10AppearsAsFirstOrLastElementOfAnArray {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter the size of the array: ");
        int size = input.nextInt();

        int[] array = new int[size];

        System.out.println("Enter the elements of the array: ");
        for (int i = 0; i < size; i++) {
            array[i] = input.nextInt();
        }

        boolean result = false;

        if (size >= 2) {
            result = array[0] == 10 || array[size - 1] == 10;
        }

        System.out.println(result);
    }
}
```

**Test Cases:**

**Normal Case:**

* Input: 10, -20, 0, 30, 40, 60, 10
* Output: true

**Corner Cases:**

* **Size of the array is less than 2:**
    * Input: 10
    * Output: false
* **10 appears only in the middle of the array:**
    * Input: 1, 2, 10, 4, 5
    * Output: false
* **10 appears neither in the first nor last element:**
    * Input: 1, 2, 3, 4, 5
    * Output: false
