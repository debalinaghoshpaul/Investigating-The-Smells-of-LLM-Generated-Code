**Java program to create a string from two given strings:**

```java
import java.util.Scanner;

public class CreateString {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // Get the two strings from the user.
        System.out.print("Enter the first string: ");
        String firstString = input.nextLine();

        System.out.print("Enter the second string: ");
        String secondString = input.nextLine();

        // Create a new string to store the combined characters.
        String combinedString = "";

        // Iterate over the first string and add each character to the combined string.
        for (int i = 0; i < firstString.length(); i++) {
            combinedString += firstString.charAt(i);
        }

        // Iterate over the second string and add each character to the combined string.
        for (int i = 0; i < secondString.length(); i++) {
            combinedString += secondString.charAt(i);
        }

        // Print the combined string.
        System.out.println("The combined string is: " + combinedString);
    }
}
```
