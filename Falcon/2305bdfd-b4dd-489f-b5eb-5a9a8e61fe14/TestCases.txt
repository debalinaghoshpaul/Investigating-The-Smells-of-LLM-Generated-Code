**Sample Input:**
1. black is a color
2. red is a color
3. green is a color
4. blue is a color

1. black 
2. red
3. 
4. 

**Corner Cases:**
1. Empty input string
2. Input string containing only spaces
3. Input string starting with a non-color word
4. Input string containing multiple color words (first occurrence is considered)
5. Input string containing special characters or numbers at the beginning
