**Java program to find out whether a region in the current string matches a region in another string:**

```java
import java.util.Scanner;

public class StringRegionMatch {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // Get the two strings from the user
        System.out.println("Enter the first string:");
        String str1 = sc.nextLine();

        System.out.println("Enter the second string:");
        String str2 = sc.nextLine();

        // Get the starting and ending indices of the region in the first string
        System.out.println("Enter the starting index of the region in the first string:");
        int startIndex1 = sc.nextInt();

        System.out.println("Enter the ending index of the region in the first string:");
        int endIndex1 = sc.nextInt();

        // Get the starting and ending indices of the region in the second string
        System.out.println("Enter the starting index of the region in the second string:");
        int startIndex2 = sc.nextInt();

        System.out.println("Enter the ending index of the region in the second string:");
        int endIndex2 = sc.nextInt();

        // Check if the two regions match
        boolean match = str1.substring(startIndex1, endIndex1).equals(str2.substring(startIndex2, endIndex2));

        // Print the result
        if (match) {
            System.out.println("The two regions match.");
        } else {
            System.out.println("The two regions do not match.");
        }
    }
}
```
