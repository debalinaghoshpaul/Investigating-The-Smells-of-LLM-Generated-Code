**Java Program:**

```java
import java.util.Scanner;

public class StringConcatenation {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // Get the original string
        System.out.print("Enter the original string: ");
        String originalString = input.nextLine();

        // Get the number of times to concatenate
        System.out.print("Enter the number of times to concatenate: ");
        int numConcatenations = input.nextInt();

        // Validate the input
        if (numConcatenations < 1) {
            System.out.println("Invalid number of concatenations. Must be a positive integer.");
            return;
        }

        // Concatenate the string with itself
        String concatenatedString = "";
        for (int i = 0; i < numConcatenations; i++) {
            concatenatedString += originalString;
        }

        // Print the concatenated string
        System.out.println("The concatenated string is: " + concatenatedString);
    }
}
```

**Test Cases:**

**Test Case 1:**

* Original String: "Hello"
* Number of Concatenations: 3

**Expected Output:**

```
The concatenated string is: HelloHelloHello
```
