```java
import java.util.Scanner;

public class CountCharacterOccurrences {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Get the input string
        System.out.println("Enter a string: ");
        String inputString = scanner.nextLine();

        // Get the character to count
        System.out.println("Enter the character to count: ");
        char characterToCount = scanner.nextLine().charAt(0);

        // Count the number of occurrences of the character in the string
        int count = 0;
        for (int i = 0; i < inputString.length(); i++) {
            if (inputString.charAt(i) == characterToCount) {
                count++;
            }
        }

        // Print the number of occurrences of the character
        System.out.println("The number of occurrences of the character '" + characterToCount + "' in the string '" + inputString + "' is: " + count);
    }
}
```

### Test Cases:

**Normal Cases:**

- Input String: "Hello World"
- Character to Count: 'l'
- Expected Output: 3

- Input String: "abracadabra"
- Character to Count: 'a'
- Expected Output: 5

- Input String: "1234567890"
- Character to Count: '5'
- Expected Output: 1

**Corner Cases:**

- Input String: "" (empty string)
- Character to Count: 'a'
- Expected Output: 0

- Input String: null
- Character to Count: 'a'
- Expected Output: NullPointerException

- Input String: "Hello World"
- Character to Count: 'z'
- Expected Output: 0

- Input String: "1234567890"
- Character to Count: 'a'
- Expected Output: 0
