**Java program to convert an array of sorted items into a binary search tree:**

```java
public class Main {
    public static void main(String[] args) {
        int[] arr = {2, 4, 6, 8, 10, 12, 14};
        Node root = buildTree(arr, 0, arr.length - 1);
        inorderTraversal(root);
    }

    private static Node buildTree(int[] arr, int start, int end) {
        if (start > end) {
            return null;
        }

        int mid = (start + end) / 2;
        Node root = new Node(arr[mid]);
        root.left = buildTree(arr, start, mid - 1);
        root.right = buildTree(arr, mid + 1, end);
        return root;
    }

    private static void inorderTraversal(Node root) {
        if (root != null) {
            inorderTraversal(root.left);
            System.out.print(root.data + " ");
            inorderTraversal(root.right);
        }
    }

    private static class Node {
        int data;
        Node left;
        Node right;

        public Node(int data) {
            this.data = data;
        }
    }
}
```

**Test cases:**

* **Normal case:** Input array: {2, 4, 6, 8, 10, 12, 14}. Expected output: 2 4 6 8 10 12 14
* **Empty array:** Input array: {}. Expected output: Empty tree
* **Single element array:** Input array: {10}. Expected output: 10
* **Array with duplicate elements:** Input array: {2, 4, 6, 8, 8, 10, 12, 14}. Expected output: 2 4 6 8 8 10 12 14

**Java program to find the number of bits required to flip to convert two given integers:**

```java
public class Main {
    public static void main(String[] args) {
        int a = 10;
        int b = 15;
        int count = countBitsToFlip(a, b);
        System.out.println(count);
    }

    private static int countBitsToFlip(int a, int b) {
        int count = 0;
        int xor = a ^ b;
        while (xor > 0) {
            if ((xor & 1) == 1) {
                count++;
            }
            xor >>= 1;
        }
        return count;
    }
}
```

**Test cases:**

* **Normal case:** Input: a = 10, b = 15. Expected output: 2
* **Zero input:** Input: a = 0, b = 0. Expected output: 0
* **Negative input:** Input: a = -10, b = 15. Expected output: 32
* **Large input:** Input: a = 1000000000, b = 999999999. Expected output: 1
