```java
public class ExpressionEvaluation {

    public static void main(String[] args) {
        // a) 101 + 0) / 3
        System.out.println((101 + 0) / 3); // 33

        // b) 3.0e-6 * 10000000.1
        System.out.println(3.0e-6 * 10000000.1); // 3.00000003

        // c) true && true
        System.out.println(true && true); // true

        // d) false && true
        System.out.println(false && true); // false

        // e) (false && false) || (true && true)
        System.out.println((false && false) || (true && true)); // true

        // f) (false || false) && (true && true)
        System.out.println((false || false) && (true && true)); // false
    }
}
```

**Test cases including corner cases:**

* **Corner case 1:** `(0 + 0) / 0` - This expression will throw an `ArithmeticException` because division by zero is undefined.
* **Corner case 2:** `true && false` - This expression will evaluate to `false` because the `&&` operator requires both operands to be true.
* **Corner case 3:** `(true || false) && (false || true)` - This expression will evaluate to `true` because the `||` operator evaluates to `true` if either operand is true. The parentheses around the `false || true` expression are not necessary.
* **Corner case 4:** `(false || false) || (true || false)` - This expression will evaluate to `true` because the `||` operator evaluates to `true` if either operand is true.
* **Corner case 5:** `!true` - This expression will evaluate to `false` because the `!` operator negates the operand.
* **Corner case 6:** `!!false` - This expression will evaluate to `true` because the `!!` operator negates the operand twice, effectively returning the original value.
