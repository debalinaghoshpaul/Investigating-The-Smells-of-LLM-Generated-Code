# Investigating-The-Smells-of-LLM-Generated-Code
Large Language Models (LLMs) are increasingly being used to generate program code. There is far less research done on code quality. In this study, we evaluate the code smells, an important indicator of code quality, of the Java programs generated in response to prompts given to four stateof- the-art LLMs: Gemini Pro, ChatGPT, Codex, and Falcon.
