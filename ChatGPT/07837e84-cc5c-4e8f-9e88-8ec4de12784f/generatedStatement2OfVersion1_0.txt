

In this program, we use the bitwise operation `&` to check if the given integer `n` is a power of 2. If `(n & (n-1)) == 0`, then the integer is a power of 2. This is because in binary representation, a power of 2 will have only one '1' bit set and all other bits will be '0'. By subtracting one from a power of 2, all the bits before the '1' bit will be set to '1' and the '1' bit will be set to '0'. So, when we bitwise AND the original number `n` with `n-1`, we get 0 if `n` is a power of 2.
