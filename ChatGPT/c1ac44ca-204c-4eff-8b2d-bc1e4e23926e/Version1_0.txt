```java
import java.util.Scanner;

public class FindSmallestNumber {

    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // Read the three numbers from the user
        System.out.print("Input the first number: ");
        double firstNumber = input.nextDouble();

        System.out.print("Input the second number: ");
        double secondNumber = input.nextDouble();

        System.out.print("Input the third number: ");
        double thirdNumber = input.nextDouble();

        // Find the smallest number using the Math.min() method
        double smallestNumber = Math.min(firstNumber, Math.min(secondNumber, thirdNumber));

        // Print the smallest number
        System.out.println("The smallest value is " + smallestNumber);
    }
}
```

**Test Cases:**

**Normal Cases:**

* Input: 25, 37, 29
* Expected Output: The smallest value is 25.0

* Input: 10.5, 15.2, 7.3
* Expected Output: The smallest value is 7.3

* Input: -5.1, -3.2, -7.6
* Expected Output: The smallest value is -7.6

**Corner Cases:**

* Input: 0, 0, 0
* Expected Output: The smallest value is 0.0

* Input: Double.MAX_VALUE, Double.MAX_VALUE, Double.MAX_VALUE
* Expected Output: The smallest value is Infinity

* Input: Double.MIN_VALUE, Double.MIN_VALUE, Double.MIN_VALUE
* Expected Output: The smallest value is -Infinity

* Input: 10.0, 10.0, 10.0
* Expected Output: The smallest value is 10.0

* Input: -10.0, -10.0, -10.0
