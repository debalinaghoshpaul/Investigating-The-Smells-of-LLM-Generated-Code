

**Test Cases:**

**Positive Test Cases:**

* **Input:**
    * Array1: [1, 3, -5, 4]
    * Array2: [1, 4, -5, -2]
* **Expected Output:**
    * Result: 1 12 25 -8

* **Input:**
    * Array1: [2, 4, 6, 8]
    * Array2: [1, 3, 5, 7]
* **Expected Output:**
    * Result: 2 12 30 56

* **Input:**
    * Array1: [0, 0, 0]
    * Array2: [1, 2, 3]
* **Expected Output:**
    * Result: 0 0 0

**Negative Test Cases:**

* **Input:**
    * Array1: []
    * Array2: [1, 2, 3]
* **Expected Output:**
    * Error: Array1 is empty

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: []
* **Expected Output:**
    * Error: Array2 is empty

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: [1, 2]
* **Expected Output:**
    * Error: Arrays are not of equal size

* **Input:**
    * Array1: [1, 2, 3]
    * Array2: [1, null, 3]
* **Expected Output:**
    * Error: Array2 contains null value

**Corner Cases:**

* **Input:**
    * Array1: [Integer.MAX_VALUE, Integer.MAX_VALUE]
    * Array2: [Integer.MAX_VALUE, Integer.MAX_VALUE]
* **Expected Output:**
    * Result: Overflow error

* **Input:**
    * Array1: [Integer.MIN_VALUE, Integer.MIN_VALUE]
    * Array2: [Integer.MIN_VALUE, Integer.MIN_VALUE]
* **Expected Output:**
    * Result: Overflow error
