### **Compute the Number of Trailing Zeros in a Factorial**

```java
import java.util.Scanner;

public class ComputeTrailingZerosInFactorial {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Read the number from the user
        System.out.println("Enter the number:");
        int n = scanner.nextInt();

        // Initialize the number of trailing zeros to 0
        int trailingZeros = 0;

        // Compute the number of trailing zeros
        for (int i = 5; i <= n; i += 5) {
            int temp = i;
            while (temp % 5 == 0) {
                trailingZeros++;
                temp /= 5;
            }
        }

        // Print the number of trailing zeros
        System.out.println("The number of trailing zeros in " + n + "! is: " + trailingZeros);
    }
}
```

**Test Cases:**

* **Corner Cases:**
    * n = 0 (expected output: 0)
    * n = 1 (expected output: 0)
    * n = 5 (expected output: 1)
    * n = 10 (expected output: 2)
    * n = 25 (expected output: 6)

* **Positive Test Cases:**
    * n = 100 (expected output: 24)
    * n = 1000 (expected output: 249)
    * n = 10000 (expected output: 2499)

* **Negative Test Cases:**
    * n = -1 (expected output: Invalid input)
    * n = -5 (expected output: Invalid input)
    * n = -10 (expected output: Invalid input)
