

This Java program defines a `FactorialCalculator` class with a `main` method and a `calculateFactorial` method. The `calculateFactorial` method is a recursive method that calculates the factorial of a given positive integer `n`. The base case is when `n` is 0, in which case the method returns 1. If `n` is not 0, the method recursively calls itself with `n-1` until it reaches the base case.

In the `main` method, we test the `calculateFactorial` method by calculating the factorial of the number 5 and printing the result. You can change the `number` variable in the `main` method to calculate the factorial of a different number.
