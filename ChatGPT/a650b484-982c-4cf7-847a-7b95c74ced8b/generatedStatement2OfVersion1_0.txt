

This program defines a `DifferenceCalculator` class with a `main` method and a `findDifference` method. In the `main` method, an array of integers is created and the `findDifference` method is called to calculate the difference between the largest and smallest values in the array. The `findDifference` method iterates over the array to find the largest and smallest values, and then calculates and returns the difference between them.
