

Test cases:

* **Corner cases:**
    * An array with all positive numbers: `[1, 2, 3, 4, 5]`
    * An array with all negative numbers: `[-1, -2, -3, -4, -5]`
    * An array with only one element: `[0]`
* **Normal cases:**
    * An array with both positive and negative numbers: `[-2, 3, 4, -1, -3, 1, 2, -4, 0]`
    * An array with positive and negative numbers in alternating order: `[-1, 1, -2, 2, -3, 3, -4, 4]`
    * An array with positive and negative numbers in random order: `[-4, -3, -2, -1, 0, 1, 2, 3, 4]`
