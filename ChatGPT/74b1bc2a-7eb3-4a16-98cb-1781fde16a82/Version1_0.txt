```java
import java.util.ArrayList;
import java.util.List;

public class FilterEvenOdd {

    public static void main(String[] args) {
        // Create a list of integers
        List<Integer> numbers = new ArrayList<>();
        numbers.add(1);
        numbers.add(2);
        numbers.add(3);
        numbers.add(4);
        numbers.add(5);
        numbers.add(6);
        numbers.add(7);
        numbers.add(8);
        numbers.add(9);
        numbers.add(10);

        // Filter out even numbers
        List<Integer> evenNumbers = numbers.stream()
                .filter(n -> n % 2 == 0)
                .toList();

        // Filter out odd numbers
        List<Integer> oddNumbers = numbers.stream()
                .filter(n -> n % 2 != 0)
                .toList();

        // Print the results
        System.out.println("Even numbers: " + evenNumbers);
        System.out.println("Odd numbers: " + oddNumbers);
    }
}
```

**Test cases:**

* **Empty list:** The program should not break if the input list is empty.
* **List with all even numbers:** The program should filter out all even numbers.
* **List with all odd numbers:** The program should filter out all odd numbers.
* **List with a mix of even and odd numbers:** The program should filter out the even and odd numbers correctly.
* **List with duplicate numbers:** The program should filter out duplicate numbers correctly.
* **List with negative numbers:** The program should handle negative numbers correctly.
* **List with zero:** The program should handle zero correctly.
